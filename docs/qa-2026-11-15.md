## Fix these first

1. **"Bet together" from a group is broken.** The group page's button opens `/new?group=<id>`, but the create form only reads `?clan=<id>` (`frontend/src/pages/CreateSeries.tsx:77`). The form opens blank: no group name, no member list, and nobody from the group is added to the lobby. The old `?clan=` link still works, so the button is linking to the wrong parameter name.
2. **Reminders can be turned on but never appear.** "Remove notification badges" (`f1b38a2`) took the Reminder tags out of Your moves. Reminders are still fetched and silently marked read, but no screen shows them. Profile still says "Reminders show in Your moves", and the browser test for reminders fails on this.
3. **The real database is missing `my_credits`.** Every other function from migrations 0016–0021 is on the real project, including `complete_tutorial` from the same file. `my_credits` answers "function not found", so on the live site the credit count in the sidebar and lobby won't load. Re-run its `create function` from `202611140021_tutorial_credits.sql`, then reload the API schema (Settings → API → Reload).
4. **Phones still put the whole menu above every page, and it's worse than yesterday.** Home's content starts 660px down. On a bet page the wager form starts 1,348px down (it was about 1,200).
5. **Share cards still say "Alea".** The Wrapped story, the Wrapped share card (`ALEA ✳ WRAPPED`, file `alea-wrapped-2026.png`, "Back to Alea") and the series recap card (`ALEA ✳ SERIES RECAP`) all use the old name. These are the pictures people post, so outsiders see the old brand.
